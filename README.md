# Software Engineering Study Jam

This repository contains the teaching materials for the **Software Engineering Study Jam**.

## Directory Structure

* `session_1/` — Teaching materials for Session 1
* `session_2/` — Teaching materials for Session 2
* `activities/` — All hands-on activities and exercises used throughout the sessions

The `session_1` and `session_2` directories contain the lesson materials, while all activities are organized separately in the `activities` directory.
